
# My First Git Project

## Description
This is a simple website I created using HTML, CSS,
and JavaScript. I created this project to practice
using Git and GitHub for version control, and I already 
have some experience with github so this should be fun!
I also added my favorite colors to make it look pretty. 

## How to Run
Download the project files and open index.html
in a web browser.

## Features
- Simple homepage
- Light blue background
- Colorful headings
- Purple interactive button
- Display a message when button is clicked
